A web-based TV and weather forecast application.

## Overview

A web-based TV and weather forecast application.

## Features

- Web TV playback interface.
- Weather forecast display.
- Static frontend project that is easy to deploy.
- Suitable for browser and large-screen scenarios.

## Quick Start

- Enter the `CloudCast TV` directory.
- Preview it with a local static server, for example `python -m http.server`.
- Open the local URL in a browser.

## Configuration

- If external weather or media sources are used, configure them according to the endpoints in the source code.

## Tech Stack

- JavaScript
- HTML/CSS
- weather/media data
